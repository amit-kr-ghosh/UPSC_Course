# Lesson Notes

Store one Markdown file per lesson or closely related topic. Suggested filename: `YYYY-MM-DD-module-XX-topic-slug.md`.

Include module and syllabus connection, learning objectives, clear explanation, constitutional/statutory references, examples and judgments, Prelims distinctions, Mains dimensions, PYQs with verification labels, recap, learner's demonstrated understanding, unresolved doubts and revision action.

Label AI-created questions as original practice, never as UPSC PYQs.
