# Quizzes and Assessments

Store lesson quizzes, module tests and cumulative tests.

## Internal preparation — not displayed before the quiz

Record the date, module/topic, learning objectives tested, syllabus connection, assessment type, source, PYQ identifiers and exact verification labels, answer-key source and instructions. Use this information to construct a valid assessment, but do not show it as a separate pre-quiz brief or make the learner scroll past it.

## Learner-facing format

Begin directly with:

```markdown
# THE ACTUAL ASSESSMENT STARTS HERE

[First question appears immediately.]
```

Do not place a Part A, verification table, course-position panel or administrative checklist before the questions.

For every question, record the learner's answer, confidence/guess status, correctness, correct answer and source, option-wise explanation and error category.

## Result and follow-up — repository record

Record score and denominator, weak concepts, re-teaching, revision action and evidence of demonstrated understanding.

Keep actual UPSC PYQs distinct from tutor-created practice. Never upgrade provisional PYQ verification labels.
