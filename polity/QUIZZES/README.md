# Quizzes and Assessments

Store lesson quizzes, module tests and cumulative tests. Keep the assessment setup separate from the questions themselves.

## Required structure for each quiz

### Assessment brief and verification
Record date, module/topic, learning objectives tested, syllabus connection, assessment type, source, PYQ identifiers and their exact verification labels, answer-key source and instructions. Identify tutor-created questions as original practice.

---

# QUIZ / ASSESSMENT STARTS HERE

Place the actual questions and options below this heading. Do not put questions before it.

For every question, record the learner's answer, confidence/guess status, correctness, correct answer and source, option-wise explanation and error category.

## Result and follow-up
Record score and denominator, weak concepts, re-teaching, revision action and evidence of demonstrated understanding.

Keep actual UPSC PYQs distinct from tutor-created practice. Never upgrade provisional PYQ verification labels.
